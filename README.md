# AI Mail Reply - Chrome 插件

在网易邮箱、QQ邮箱、Gmail、Outlook 中直接使用 AI 回复邮件。

## 安装步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件夹（ai-mail-reply）
5. 插件安装完成 ✅

## 首次使用

1. 点击插件图标 → 「设置 API Key」
2. 填入至少一个 AI 服务商的 API Key（推荐 Claude 或 DeepSeek）
3. 打开网易邮箱，打开一封邮件
4. 点击右下角紫色「✦」按钮
5. 选择 Skill → 点击「生成回复」
